# Work execution brief — VOID ATLAS

## Goal
Produce a polished, one-day, browser-first digital artwork that can be reviewed for a job portfolio. The initial canvas prototype exists in `index.html`. Its existence is not evidence of production readiness.

## Tasks for Work
1. Inspect this repository and preview the current prototype; do not invent successful tests.
2. Identify 3–5 credible art-direction references (do not copy code, assets, names, or layouts); produce `ART_DIRECTION.md` (palette, typography, spacing, motion, accessibility).
3. Audit desktop/mobile hierarchy, contrast, keyboard usability, scene distinction, reduced motion, and touch control. Record actionable issues in `REVIEW.md`.
4. Pass the actionable issues to Codex as repository tasks, prioritize blockers, and review the new preview after implementation.
5. Produce `PORTFOLIO_CASE_STUDY.md` with concept, interaction, technical stack, process, user contribution fields marked TODO, and clear AI assistance disclosure. Do not invent outcomes or employment experience.
6. If authenticated deployment tools are available and permitted, deploy static site and validate the live URL. If blocked, provide exact manual publishing steps and report the blocker.

## Scope limits
No paid APIs, no external model files, no fabricated metrics, no copying proprietary art, no misleading claims of a 3A render. Build one stable polished experience rather than expanding indefinitely.
